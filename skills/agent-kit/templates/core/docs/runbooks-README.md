# Runbooks

Operational procedures for this project — anything a person or agent needs to *do* rather than
*know*: deploy steps, recovery procedures, environment setup, the smoke test.

Rules:

- One procedure per file, imperative steps, copy-pasteable commands.
- If an agent works out a procedure the hard way, it writes the runbook before the knowledge
  evaporates (AGENTS.md §11).
- Runbooks state their verification: how you know the procedure worked.

Start with `smoke-test.md` — the standing end-to-end check for this project.
